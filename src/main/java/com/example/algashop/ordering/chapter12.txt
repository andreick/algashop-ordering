12. Application Services e a camada de Application

12.1. Application Services Pattern

- Orquestram os casos de uso e fluxos da aplicação, protegendo a camada de domínio.
- São uma ponte entre a camada de apresentação (controllers) e a camada de domínio (services, aggregates).
- Gerenciam a lógica de aplicação, como transações, segurança, e coordenação de chamadas a serviços de domínio.
