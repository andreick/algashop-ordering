8 Repositories e infraestrutura de persistência

8.1. Repository Pattern

O Repository Pattern é uma coleção de objetos do domínio em memória que simula uma coleção de objetos persistidos. Ele fornece uma interface para acessar os dados, permitindo que a lógica de negócios interaja com os dados sem se preocupar com os detalhes de como eles são armazenados ou recuperados.
Um Repository pertence a um Aggregate Root.

Benefícios do Repository Pattern:
- Abstração da camada de persistência
- Promove um design mais limpo e organizado
- Separa o modelo de domínio da tecnologia de persistência
- Facilita a manutenção, evolução e testes do código
