13. Domain Events

13.1. Domain Event Pattern

Evento = Fato importante + Ferramenta de modelagem
Anti-padrão: Eventos CRUD
Não crie eventos, os descubra!

Domain Event Pattern:
- Nome deve ser uma sentença no passado
- Nomeado conforme a linguagem ubiqua do domínio
- Representam fatos importantes
- São imutáveis
- Gerados por agregados

Propriedades:
- Data e hora do evento
- ID do agregado que gerou o evento
- Payload com dados relevantes para o evento

Recomendações:
- Não inclua objetos complexos no payload
- Não inclua muitos dados nem dados externos ao agregado
